# Проект автоматизации тестирования с интеграцией Allure-отчетов

Проект содержит автоматизированные сценарии тестирования
медленного калькулятора и интернет-магазина Saucedemo. 
Реализован на языке Python с использованием фреймворка 
PyTest и паттерна проектирования Page Object Model (POM). 
Код полностью задокументирован и содержит строгую аннотацию типов.

## Системные требования
- Python 3.10+
- Браузеры: Google Chrome, Mozilla FireFox
- Установленная в операционной системе утилита Allure CLI (для компиляции отчетов)

## Инструкция по работе с проектом

### 1. Запуск автотестов и сбор результатов
Для запуска всех тестов из папки `lesson_10` 
и генерации сырых логов Allure в директорию `allure-results`, 
выполните команду:
```bash
pytest --alluredir=allure-results lesson_10/
```

### 2. Генерация и просмотр красивого веб-отчета
Чтобы скомпилировать собранные данные в интерактивный локальный 
веб-интерфейс отчёта и автоматически открыть его в браузере, выполните:
```bash
allure serve allure-results
```
